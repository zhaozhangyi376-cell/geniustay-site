关于我A short self-introduction

3 min read

我叫赵彰益，也可以叫我 Geniusaty，目前是南方科技大学电子信息博士，研究方向是 AI for 射频器件。

本科毕业于中国民航大学电气工程专业，绩点专业第一，推免直博。科研之外，我在 2025 年创办了 界越未来教育科技有限公司，服务 200+ 大学生客户，实现正向现金流，客户续费率 80%。

同年年底与伙伴共同发起 AgentAlpha 社区，聚焦多模态大模型与 Agent 技术落地， 孵化开源项目 Idea2Paper，在 GitHub 上斩获 1200+ star，登上 Hugging Face 当日榜一。

博士入学后，我继续打磨技术、拓展技术栈，随后进入六百亿规模创投机构达晨财智与南科大联合创办的首届达晨班， 开启从技术判断走向创投实践的新阶段。

走到今天，我越来越确定自己想做的不是堆叠身份，而是把相信的事情真正做出来： 把理想打磨成细节，把选择落成行动。
